# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [1.0.0] - 2026-09-23

### Added

* Reusable GitHub repository template baseline
* Standard issue and pull request templates
* Consistent repository label configuration
* Dependabot configuration for GitHub Actions
* Automated label synchronisation
* Release Please release management
* Security and support documentation
* SHA-pinned GitHub Actions dependencies

### Changed

* Standardised the default branch on `main`
* Simplified repository documentation and configuration
* Updated workflows to use least-privilege permissions
* Improved security reporting guidance for private vulnerability reporting
* Cleaned and standardised issue forms and repository labels

### Removed

* Legacy repository generator tooling
* Generic CI and CodeQL workflows
* Pre-commit configuration and workflow
* GitHub Pages content
* Legacy bot configuration
* Project-specific funding and CODEOWNERS configuration
* Personalisation, licence-update and repository-download automation
* Obsolete roadmap and legacy template boilerplate
